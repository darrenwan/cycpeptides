# Bugbot review rules — cycpeptides (PD-L1 macrocycle campaign)

Pure in-silico campaign. Review **changed lines** for deviations from the gates below.
Prefer actionable findings with a concrete fix. Do not invent wet-lab or clinical scope.

Authoritative campaign state: `data/targets/PDL1/roadmap.yaml`.
Gate thresholds: `data/targets/PDL1/thresholds_v1.yaml`.
Runtime contract: `CLAUDE.md`.

## Blocking findings

### Runtime / environment
- Flag any campaign script or shell driver that invokes system/conda `python` for `scripts/pdl1_*.py`. Require `uv run python scripts/...` (or `uv run ruff ...`).
- Flag adding `torch`, `jax`, `jaxlib`, `tensorflow`, or CUDA packages to `pyproject.toml` / project venv. GPU stacks belong in Docker images only (`pdl1-afcyc`, RFpeptides, ProteinMPNN containers).
- Flag hardcoded absolute paths to sibling projects (e.g. `/mnt/data4t/aidd/...` other than this repo, or `/mnt/data4t/kg_project/...`) in runtime code. Assets must resolve under this repo (`models/`, `third_party/`) or via env overrides `RFD_MODELS_DIR`, `PROTEINMPNN_DIR`, `AFCYC_PARAMS_DIR`.

### Secrets / credentials
- Flag GitHub PATs, API keys, or passwords embedded in remote URLs, scripts, docs, or commits (`ghp_`, `github_pat_`, `AKIA…`, etc.). Require scrubbing and rotation notes.
- Flag committing `.env`, credential JSON, or private keys.

### Git hygiene / large binaries
- Flag adding files that `.gitignore` is meant to exclude: `models/**/*.pt`, `models/afcyc/params/`, `models/academic/*.whl`, `third_party/ColabDesign/`, ProteinMPNN `*.pt` weights, smoke `traj/` / `*.pdb` / `*.trb` / `*.fa` / logs, `*.bak`, `*WRONG*`.
- Flag hand-editing generated `PDL1_IgV_5O45_A18-134.pdb`; it must be regenerated by `scripts/pdl1_prepare_receptor.py`.

### Scientific gate policy (do not reinvent)
- Primary pass/fail gate is `pd1_jaccard` vs `T_pd1_jaccard` from `thresholds_v1.yaml` (currently `0.15`). Flag replacing it with unrelated primary filters without updating calibration + thresholds file together.
- Rim residues A122/A124/A125 are a **soft weighted `rim_score`** for ranking/quota only. Flag any `require(D122 and K124 and R125)` / `require_all_three` / hard AND over all three rim contacts. `forbid_require_all_three: true` is intentional (all 5 crystal positives fail that AND).
- Flag hardcoding a new `T_pd1_jaccard` (or rim weights) in scripts instead of reading `thresholds_v1.yaml`, unless the PR also re-runs/updates calibration provenance.
- Track A (5O45 de novo) and Track B (8ALX/pAC65 redesign) must not share evaluation criteria or silently mix selection quotas.

### Pipeline integrity
- S2 is incomplete without AfCycDesign outputs. Flag smoke/scoring paths that mark S2 done when AfCyc predictions are missing, or that skip AfCyc without failing loudly.
- Metric definitions (`pd1_jaccard`, `rim_*`, `rim_score`, `rmsd_vs_8alx`) must stay single-sourced in `scripts/pdl1_blockade_metrics.py` (`score_complex`). Flag duplicated divergent formulas in other scorers.
- Flag chain-role swaps in RFpeptides/MPNN drivers: binder = chain A, PD-L1 = chain B (MPNN designs A, fixes B), unless the change is explicitly about the documented 5O4Y exception.

### Docker / pins
- Flag loosening AfCyc image pins without justification: `jax[cuda12]==0.4.30`, `dm-haiku==0.0.12`, `numpy==1.26.4`, ColabDesign **v1.1.3**. Breaking these historically breaks haiku/AF2.
- Flag baking AF2 params or cloning ColabDesign inside the Dockerfile when the contract is host-mount / `fetch_colabdesign.sh`.

## Non-blocking (should-fix)

- Prefer editing `data/targets/PDL1/roadmap.yaml` status/DoD when a stage actually completes; avoid claiming S2/S3 done in docs alone.
- New metrics or filters should record provenance (script, inputs, seed, date) next to outputs under `results/PDL1/`.
- Shell smoke scripts should keep mounts minimal (cropped receptor as `/inputs/receptor.pdb`, weights read-only `/models`) and write under `results/PDL1/smoke/`.
- Avoid absolute hardcoded `ROOT` in new scripts; derive from `__file__` (exception already exists in `pdl1_hotspot_consensus.py` — do not copy that pattern).

## Out of scope (do not flag)

- Absence of a unit-test suite / CI — verification is script DoD + re-run, by design.
- Large binaries present on disk locally but gitignored.
- Chinese narrative docs style, unless they contradict `thresholds_v1.yaml` or runtime rules above.
- Pure documentation typos with no behavioral impact.
