结构审计与修复优先级

对 S0–S2 三层管线（校准 / 三阶段生成 / 评分）的逐环核查。技术选型与门控哲学是内行的， 但评分链路存在一处编号契约断裂，使 S2 的全部指标失效——报告中的 PASS 是假阳性。

P0 通过：报告 0/16  →  实际 16/16

S2 冒烟中 pass_P0 = 0/16 不是"设计质量差"，是算错了。 修正编号后，同一批 AfCyc 预测结构有 16 条全部通过主门控，jaccard 落在 0.30–0.52——而晶体阳性基线是 0.29–0.67。

P0 编号契约断裂

阻断性缺陷。修复前，pdl1_blockade_metrics.py:35 的 RIM_RESIDUES = (122, 124, 125) 与 footprint 集合都按 UniProt IgV 编号书写，而它实际接收到的 PD-L1 链已被 归零重编号为 1..117。查不到残基 → 静默返回 0。

根因：编号在两个阶段之间连续丢失两次

为什么这个 bug 躲过了三层检查

  • binder 链恰好是巧合。 设计的环肽在 RFpeptides 与 AfCyc 两处都是 1..12（原始设计就从 1 开始），只有 PD-L1 链移位。看起来就像 "只有 target 链的指标偏低"，而不像坐标系错误。
  • S1 校准拦不住。 校准跑的是晶体结构（7OUN 18..134、 8ALX 20..134、5O45 17..145），它们天生带 UniProt 编号， 所以 min_positive_jaccard = 0.2917 是真值。 设计侧走归零编号——校准与评分实际用了两套坐标系，而两侧都没有断言坐标系一致。
  • DoD 只验存在性。 pdl1_smoke_score.py 只断言 len(df) >= 1 与数据源为 AfCyc 预测——0/16 通过照样报 PASS。 这是本次事故的直接放行者。

一个反证：现状表格并非整列全零， pdl1_cyc_2_sample1/2 的 jaccard 为 0.0400 / 0.0357。 原因是那些结构的局部残基 56（真实 73）通过绝对编号巧合撞上了 footprint 中的 56。这种"偶尔非零"比整列全零更危险——它让错误看起来像信号。

修复方案

不要在每级 Docker 阶段外面补 +17——那是脆弱且必然再犯的做法。应在 度量层做序列锚定的编号归一：

  1. 在 pdl1_blockade_metrics.py 增加 resolve_numbering(structure, ref_seq)， 用参考受体序列对齐目标链，建立 局部 → UniProt 映射，由 score_complex() 内部统一转换。
  2. 增加不变量断言：目标链残基数或序列与参考不符时直接抛错，而不是静默算 0。
  3. 增加 scripts/pdl1_selftest_metrics.py：把 8ALX / 7OUN 晶体经由 score_complex() 跑一遍，断言 jaccard 等于校准值（0.4400 / 0.6667）。 这一个自检就能立刻抓到本次事故。

已实测映射可靠：AfCyc 输出链 B 与裁剪受体的 117 个残基序列 逐一对齐（117/117 完全一致），因此序列锚定的偏移量是唯一解，可安全自动化。

P1 科学问题

1 · 阴性对照是"不可能失败"的对照

n_negatives = 4 全部为合成负例：3 个把肽平移 +50 Å 的 decoy，加 1 个 apo。 max_negative_jaccard = 0.0、min_positive = 0.2917， "完美可分"是必然的，不构成对 T = 0.15 的有效验证—— 平移 50 Å 的肽当然不接触界面。要证明该阈值有判别力，需要真负例：

  • AfCyc 预测的打乱序列肽（同长度、同骨架，非设计序列）
  • 结合 PD-L1 非 PD-1 面的肽（IgC 域、5X8M 型表位）
  • 其他靶点的环肽

否则 0.15 是从"能接触界面"到"完全脱离"的中点，而不是"阻断 PD-1"的判据。

2 · 30% 多样性配额在当前定义下无法执行

rmsd_vs_8alx 要求肽等长（len(ref_pep) != len(mov_pep) → None）。 实测 8ALX 的 pAC65 是 15 残基（7 个标准残基 + 8 个非标准残基 MAA/DPP/HYP/DAB/V6W/9KK×2/CCS，其中 CCS 同时是环化桥）， 而 RFpeptides 输出为 12/14/15/16 残基。

rmsd_vs_8alx 对轨道 A 几乎恒为 None （smoke_metrics.csv 整列为空印证了这点），S5 的 high_rmsd_quota_frac: 0.3 因此无法运行——而"反向环 / 偏心遮挡" 正是本项目声称的核心差异化主轴。需要长度无关的几何差异度量：受体界面 CA 对齐后， 取肽质心偏移向量与主轴朝向角（或 5O4Y 那条 Group II 反向环的环方向指纹）。

3 · 自洽性检查目前是同义反复

pep_ca_rmsd_vs_design ≈ 0.28 Å 被冒烟报告当作 PASS 证据，但 pdl1_smoke_afcyc.sh 硬编码了 --use_binder_template 1—— 骨架作为模板喂入，0.28 Å 只说明"跟了模板"，不是独立验证。 真正的自洽性检查要么关模板重跑，要么换 HighFold 做第二模型共识 （设计文档本就写了双模型，只是没做）。

4 · 漏斗的后两层门控完全空转

design_spec.yaml §2.3 的度量契约要求 ipae / iptm / iface_plddt / ddg / cms / sap。实际情况：

  • score_complex() 一个都不产出；
  • afcyc_summary.json 里已有 plddt 0.868 / ptm 0.781 / i_ptm 0.636，却从未 join 进 smoke_metrics.csv；
  • Rosetta 那条线（pdl1-pyrosetta 镜像）建好了，但没接进任何脚本。

结果：pass_struct 与 pass_physics 在 S2 里是空转的， eligible 实际只由 P0 决定。补一个 join 步骤即可立刻激活第一层。

5 · 主门控是集合重叠，不是遮挡

设计文档承诺"Jaccard 或体积遮挡"，实现只有 Jaccard。 集合重叠对"接触了正确残基但姿态不阻断"的设计无判别力。真正的遮挡度量—— 肽原子与 PD-1 结合位点原子的重叠体积，或与 4ZQK 的姿态冲突数——才是机制读出。 这是 P0 门控科学性的核心缺口。

6 · 5O4Y 的阳性归类与差异化主轴冲突

5O4Y 被当作足迹阻断阳性（jaccard 0.2917，五者最低），但 hotspots.json 与设计文档都把它的意义定义为 Group II 反向环—— 那属于"多样性"主轴，不是"更接近 PD-1 姿态"。用反向环结构校准"阻断"阈值， 会把门控推向单一几何。建议移出阳性集，改作多样性参考。

保留 做得好的地方

这些不是客套——是重构时应当保住的判断。

rim 降级为软分，是真正的手术级判断

校准数据证明 5/5 阳性宏环都过不了 D122∧K124∧R125：7OUN 只接触 D122、 8ALX 只接触 R125、6PV9 与 5O4Y 三者皆无。把 rim 降为软分 + 配额， 避免了"门控把已知活性分子全部杀掉"这一该类项目最常见的死法。有晶体学证据支撑。

uv / Docker 的分层边界划得准

轻依赖走 uv，torch / JAX 永不进 venv；forbid_system_python 在 README、 roadmap、design_spec 三处一致声明。多数 AIDD 项目的环境腐坏都源于没划这条线。

资产自包含与溯源是完整的

models/SOURCES.md + .colabdesign_pin + 幂等的 bootstrap_local_assets.sh，摆脱 sibling 路径依赖。比绝大多数科研仓库做得好。

镜像 pin 带理由

jax 卡 0.4.30 因为 dm-haiku ≥0.0.17 需要已被 jax ≥0.5 移除的 jax.interpreters.xla.xe；numpy 卡 <2；ColabDesign 用 --no-deps 再单点装 jax。权重不进镜像、运行时挂载——都对。

S0 的科学判断是清醒的

显式声明"外表位优先、不追通透性"、显式回避 BMS 专利空间、轨道 B 降级为内部对标—— 没有把两个目标混成一个打分函数。

"先校准再大规模生成"的顺序正确

在花 GPU 跑 10k 之前先用力学对照定阈值，S1 门控里还写了 "阳性被默认门控杀光则降 T"的人工兜底。

顺序 修复优先级

第 1–2 条做完之前，S3（10k 主生成）不应启动—— 否则会用错误的门控筛掉一整轮 GPU 预算，而且筛掉的是好设计。

  1. 01
    编号归一 + 不变量断言
    P0，阻断一切。序列锚定，不补硬编码偏移。
  2. 02
    新增 pdl1_selftest_metrics.py
    晶体经 score_complex() 复现校准值——防复发。
  3. 03
    git init 并提交当前状态
    再开始改；否则这次评估本身也无法固化。
  4. 04
    收紧 smoke_score 的 DoD
    从"非空"改为"晶体自检通过 + 至少 N 条数值合理"。
  5. 05
    join plddt / ptm / i_ptm 进指标表
    数据已在 afcyc_summary.json，接上后 pass_struct 才开始有效。
  6. 06
    换长度无关的多样性度量
    rmsd_vs_8alx 退役或改名为"等长专用"。
  7. 07
    补真负例集，重校 T_pd1_jaccard
    打乱序列 + 非 PD-1 面结合肽。
  8. 08
    杂项清理
    读 pred_chain_map；删绝对路径；清 .bak。
